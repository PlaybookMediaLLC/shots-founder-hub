## Current availability

The `sfh` executable includes both the CLI and the local MCP server.

<Warning>
  Homebrew, standalone release binaries, and Windows package-manager distribution are forthcoming. Do not rely on those channels yet.
</Warning>

## Install from the desktop app

Open **Settings → Developers** and select **Install** (or **Reinstall**). Direct-download desktop builds copy the bundled CLI onto your PATH.

| Platform | Installed command | Path |
| --- | --- | --- |
| macOS | `sfh` | `~/.local/bin/sfh` |
| Linux (DEB / AppImage) | `sfh` | `~/.local/bin/sfh` |
| Windows | `sfh` | `%LOCALAPPDATA%\Shots Founder Hub\bin\sfh.exe` (added to your user PATH) |

On macOS and Linux, add `~/.local/bin` to `PATH` if your shell cannot find `sfh`:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

On Windows, open a new terminal after installing so the PATH update applies.

<Note>
  The Mac App Store build does not include bundled CLI installation. Use [build from source](#build-from-source) instead.
</Note>

## Build from source

To build the CLI yourself instead:

```bash
git clone https://github.com/PlaybookMediaLLC/shots-founder-hub.git
cd shots-founder-hub
cargo install --locked --path apps/cli
sfh --version
```

`cargo` installs the executable into its configured binary directory, normally `~/.cargo/bin`. Add that directory to `PATH` if your shell cannot find `sfh`.

## Connect to local data

By default, the CLI looks for `anarlog/app.db` in your operating system's application-data directory. It also recognizes legacy Shots Founder Hub locations.

Open the desktop app once so it can create the database. After that, the CLI and local MCP server work while the app is closed.

For a custom database location, pass a global option or environment variable:

```bash
sfh --db-path /path/to/app.db --json meetings list
ANARLOG_DB_PATH=/path/to/app.db sfh --json meetings list
```

If you have a Shots Founder Hub data directory containing `app.db`, use:

```bash
sfh --base /path/to/sfh-data --json meetings list
```

The CLI opens the database in read-only query mode for meeting reads. Proposal create and decline commands, and `sfh mcp`, open the same file for writes so they can stage or discard pending edits. They do not create a database or run migrations.
